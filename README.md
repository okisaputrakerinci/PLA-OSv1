# PLA-OSv1

**PLA-OSv1 (Plant Leaf Area – Open Software v1)** is a Python-based software for estimating plant leaf area from digital images.

The software is designed to support laboratory-scale plant phenotyping, research, and agricultural applications where leaf area measurement is required. PLA-OSv1 provides both a graphical user interface (GUI) and a command-line interface (CLI) for image-based leaf area estimation.

---

## Features

**Graphical User Interface (GUI)**
  - User-friendly interface for image-based leaf area estimation.
  - Designed for researchers and users who prefer a graphical workflow.

**Command-Line Interface (CLI)**
  - Supports command-line execution for research workflows and batch-oriented processing.
**Leaf Area Estimation**
  - Estimates leaf area from digital images.
  - Designed for controlled laboratory and research environments.

**Standalone Windows Application**
  - The project includes build and installer scripts for creating Windows applications.

**User Manual**
  - A user manual is provided in the `docs` directory.

---

## Motivation
Digital image-based measurement can provide a practical alternative to conventional manual methods for estimating leaf area.
PLA-OSv1 is developed with a focus on **lightweight and practical image-based analysis**, particularly for laboratory-scale research and controlled environments such as plant laboratories and greenhouses.
The project is intended to support researchers who need a practical software tool for repeated leaf area measurements without requiring a complex machine-learning infrastructure.
